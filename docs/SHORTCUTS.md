# Keyboard Shortcuts & Editor Commands

Press `Cmd/Ctrl + /` inside Noted at any time to open the interactive shortcuts cheat sheet.

## General & Navigation

| Action | macOS | Windows / Linux |
| :--- | :--- | :--- |
| **New Note** | `Cmd + N` | `Ctrl + N` |
| **Search Notes** | `Cmd + F` / `Cmd + K` | `Ctrl + F` / `Ctrl + K` |
| **Open Clipboard (Linux)** | — | `Super + V` |
| **Toggle Grid / List View** | `Cmd + Shift + L` | `Ctrl + Shift + L` |
| **Zen / Focus Mode** | `Cmd + Shift + F` | `Ctrl + Shift + F` |
| **View All / Pinned / Trash** | `Cmd + 1 / 2 / 3` | `Ctrl + 1 / 2 / 3` |
| **Open Settings** | `Cmd + ,` | `Ctrl + ,` |
| **Shortcuts Cheat Sheet** | `Cmd + /` | `Ctrl + /` |

## Organization & Export

| Action | macOS | Windows / Linux |
| :--- | :--- | :--- |
| **Pin / Unpin Active Note** | `Cmd + P` | `Ctrl + P` |
| **Move Note to Trash** | `Cmd + Shift + D` | `Ctrl + Shift + D` |
| **Export Note to Markdown** | `Cmd + Shift + M` | `Ctrl + Shift + M` |

## Formatting & Slash Commands (`/`)

Type `/` on a blank line to insert blocks (`/h1`, `/h2`, `/h3`, `/checklist`, `/bulletList`, `/orderedList`, `/quote`, `/codeBlock`, `/table`, `/divider`), or use Markdown triggers:

- `# `, `## `, `### ` + `Space` → Headings 1–3
- `[] ` or `- [ ] ` + `Space` → Interactive checklist
- `- ` or `* ` + `Space` → Bullet list
- `1. ` + `Space` → Numbered list
- `> ` + `Space` → Blockquote
- `Cmd/Ctrl + B / I / U / E` → Bold, Italic, Underline, Inline Code
